# stepik_sale_boost

Система прогрева студентов и лидов: Telegram-бот собирает сигналы о человеке, а скоринг по лестнице Ханта показывает, насколько он прогрет к покупке курса.

Сейчас бот работает в режиме **только чтение**: пишет события в Google-таблицу и ничего не отправляет.

## Что бот ловит

| Апдейт Telegram | Событие | Баллы |
| --- | --- | --- |
| Заявка по ссылке, имя которой начинается с `yt` | `youtube_join_request` | +1 |
| Вступление в aleron_saas | `joined_saas` | +1 |
| Комментарий в группе обсуждений | `comment` | +1, максимум +3 |
| Человек сам написал в личку @Aleron_df | `dm_incoming` | +2 |
| Ответил после нашего сообщения | `replied` | +2 |
| Получил от нас документ или ссылку | `got_guide` | +1, максимум +3 |
| Получил голосовое или кружок | `got_voice` | +1 |
| Спросил про курс, цену, программу | `asked_course` | +3 |
| Отписался от канала | `left_channel` | -1 |

Веса и ступени правятся в `crm/scoring.py`. Баллы из Степика (курсы, отзывы, свой проект) добавим отдельным импортом из "Шахты".

## Где лежат данные

Персональные данные в репо не попадают. Всё хранится в приватной Google-таблице:

- лист `events` - сырые события, бот дописывает строки;
- лист `scores` - баллы и ступень по каждому человеку, пересчитывается раз в день (`/api/rescore`).

## Настройка

1. **Бот в @BotFather:** включить Secretary Mode, выключить Group Privacy, в Channel Admin Rights оставить Invite Users.
2. **Таблица:** создать "CRM студентов", скопировать её id из URL.
3. **Сервисный аккаунт Google:** в Google Cloud включить Sheets API, создать сервисный аккаунт и JSON-ключ, расшарить таблицу на его email с правом редактора.
4. **Vercel:** импортировать этот репо, заполнить переменные из `.env.example` в Settings → Environment Variables, задеплоить.
5. **Вебхук:** локально выполнить
   ```
   TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... \
   python scripts/set_webhook.py https://<проект>.vercel.app/api/telegram
   ```
6. **Каналы:** добавить бота админом в datafeeling и aleron_saas, участником в их группы обсуждений.
7. **Профиль:** Настройки → Telegram Business → Чат-боты → добавить бота, право "Отвечать на сообщения" не давать.

## Структура

```
api/telegram.py      вебхук Telegram
api/rescore.py       пересчёт баллов (крон Vercel)
crm/events.py        апдейт -> события
crm/scoring.py       веса, лимиты, ступени
crm/sheets.py        запись и чтение Google-таблицы
scripts/set_webhook.py
```
